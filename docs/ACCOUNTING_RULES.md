# 账务规则（随实现更新）

前台不出现借贷术语；底层为复式分录。金额一律整数分。

## 分录行为（阶段 1 已实现）

| 业务 | 分录 | 说明 |
| --- | --- | --- |
| 银行卡消费 500 | 借 费用:分类 500；贷 资产:银行卡 500 | 费用增加、资产减少 |
| 信用卡消费 500 | 借 费用:分类 500；贷 负债:信用卡 500 | 负债增加 |
| 还信用卡 500 | 借 负债:信用卡 500；贷 资产:银行 500 | 阶段 1 以「转账」实现；不再记费用 |
| 自有账户互转 1,000 | 借 资产:B 1000；贷 资产:A 1000 | 不计收支 |
| 收入到账 1,000 | 借 资产:银行 1000；贷 收入:分类 1000 | — |

## 余额与口径

- 余额 = 期初 + 完整分录求和；负债类余额（欠款）= 期初 +（贷-借），溢缴为负，不取绝对值。
- 期初余额允许暂不确认：`balance_unconfirmed=true` 随账户返回，不把未知当真实零。
- 阶段 1 汇总口径：净收入 = posted 收入合计；净支出 = posted 费用合计；结余 = 收入 − 支出。转账不计。
- 业务有效日期（business_date）与操作审计时间（created_at）分开保存；日期精度记录（day/datetime）区分。

## 幂等与不变量

- (账本, operation_id) 唯一；同内容重放返回原结果，不同内容 409。
- 每笔交易 debits == credits；交易 + 分录 + 审计同一数据库事务提交。
- 正式交易不可变；阶段 2 引入原单/冲正/替代链与有效业务投影。

## 阶段 2 起新增（规划，见验收 T01–T17）

退款、报销/代付回款、错账更正与作废、收入退回、跨月口径、借还款、押金、房贷本息、期初/对账差额。
