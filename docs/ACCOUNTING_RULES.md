# 账务规则（随实现更新）

前台不出现借贷术语；底层为复式分录。金额一律整数分。

## 分录行为（阶段 1 已实现）

| 业务 | 分录 | 说明 |
| --- | --- | --- |
| 银行卡消费 500 | 借 费用:分类 500；贷 资产:银行卡 500 | 费用增加、资产减少 |
| 信用卡消费 500 | 借 费用:分类 500；贷 负债:信用卡 500 | 负债增加 |
| 还信用卡 500 | 借 负债:信用卡 500；贷 资产:银行 500 | 阶段 1 以「转账」实现；不再记费用 |
| 自有账户互转 1,000 | 借 资产:B 1000；贷 资产:A 1000 | 不计收支 |
| 收入到账 1,000 | 借 资产:银行 1000；贷 收入:分类 1000 | — |

## 余额与口径

- 余额 = 期初 + 完整分录求和；负债类余额（欠款）= 期初 +（贷-借），溢缴为负，不取绝对值。
- 期初余额允许暂不确认：`balance_unconfirmed=true` 随账户返回，不把未知当真实零。
- 阶段 1 汇总口径：净收入 = posted 收入合计；净支出 = posted 费用合计；结余 = 收入 − 支出。转账不计。
- 业务有效日期（business_date）与操作审计时间（created_at）分开保存；日期精度记录（day/datetime）区分。

## 幂等与不变量

- (账本, operation_id) 唯一；同内容重放返回原结果，不同内容 409。
- 每笔交易 debits == credits；交易 + 分录 + 审计同一数据库事务提交。
- 正式交易不可变；阶段 2 引入原单/冲正/替代链与有效业务投影。

## 冲账四类（阶段 2 已实现）

### 真实退款（refund，关联原消费）
- 支持全额/部分/多次/按拆分项，退至任意有效资金账户（含信用卡）。
- 分录：借 资产:退款账户；贷 费用:分类（或 贷 资产:应收——代付部分的商户退款）。
- 额度：整单退款累计 ≤ 原金额；拆分退款按拆分项累计 ≤ 该项金额；写事务内重校验（并发不超额，T02）。
- 退款不是收入，不直接改小原金额；原单与退款经 link_id + refund_allocations 互相可追溯。

### 报销与代付回款（settlement / reclass）
- 代付在记账时拆分：`expense` 部分进费用、`receivable` 部分（带对方）进应收。
- 回款：借 资产:账户；贷 资产:应收。不是收入，不再冲减自担费用；部分/多次/账龄支持，超额拒绝（T07）。
- 转为待报销（reclass）：把普通支出（无拆分）部分/全部转为应收——借 资产:应收；贷 费用:分类。无现金流，保留原单链与有效日期（T08）。
- 核销（writeoff）：确认无法收回时借 费用:分类；贷 资产:应收，原因必填，不自动核销。

### 错账更正与作废（revisions）
- 更正 = 技术冲正（镜像原全部分录并反向，不产生虚假退款现金流）+ 同事务过账替代版本；业务日期默认保持原日期。
- 作废 = 仅冲正。原单在 revisions 唯一约束 → 不能重复冲正。
- 依赖：有有效退款/结算的原单不能作废（dependency_blocked）；更正后金额不得小于已有效退款额（T12）。

### 收入退回（income_refund，关联原收入）
- 借 收入:分类；贷 资产:账户。累计 ≤ 原收入，不伪装成购物支出（T10）。

## 有效业务投影

- 余额 = 全部已入账分录（含冲正）求和。
- 业务统计只读有效投影：posted 且未被冲正且自身不是冲正。
- 严禁「过滤原单却累计其冲正」：冲正分录只进余额，不进业务投影（T11 验证）。

## 跨月口径（T13）

- 发生期（默认）：退款/重分类按自身发生日计入所在期间；跨期分类净支出允许为负。
- 原消费归属：调整归到原消费所在期间，计入条件为调整日 ≤ 统计截止日（当天）——截至当前的更正后口径，不虚构过去快照。
- 现金流永远按真实收付日期。

## 幂等与不变量

- (账本, operation_id) 唯一；同内容重放返回原结果，不同内容 409。
- 每笔交易 debits == credits；交易 + 分录 + 拆分 + 分摊 + 修订 + 审计同一数据库事务提交。
- 正式交易不可变；没有 update/delete 路径。
