# 小账 PRD（需求基线摘要）

> 本文档是实施用摘要，随实现更新。完整原始任务基线由项目所有者提供（2026-09-15），不并入本仓库。

## 定位

- 中文名「小账」，英文标识 XiaoZhang，代码与部署标识 `xiaozhang`，口号「日常小账，心里有数」。
- 单服务器自托管的个人与中国家庭记账 PWA。默认简体中文、人民币 CNY、账本时区 Asia/Shanghai。
- 默认一个管理员 + 一个家庭账本；支持管理员邀请家人共同记账。不做公开 SaaS。
- 核心原则：用户不需要懂会计，但系统保证账务一致。

| 项 | 默认 |

## 范围要点

1. 账户 ≠ 支付渠道；复式分录底层，前台隐藏借贷术语；金额整数分。
2. 冲账分四类：真实退款、报销/代付回款、错账更正与作废、收入退回；跨月口径可切换。
3. 分类（最多两层）、标签、模板三者独立；内置中文支出/收入/资金操作模板为幂等种子。
4. 周期规则 + 实例防重复；可解释规则与历史统计推荐，不依赖大模型；推荐不等于入账。
5. 统一定义的统计、预算、现金流预测；内部转账/本金往来/期初调整不计收支。
6. 家庭协作：服务端校验权限；关闭公开注册；邀请令牌单次、有限期、可撤销。
7. CSV/XLSX 导入（映射、去重、跨来源匹配）、导出、附件（授权访问）。
8. PWA：本地草稿 + 操作队列 + 服务器确认；幂等同步；冲突显式报错。
9. 单服务器部署：systemd 或单容器 Docker Compose；/healthz、/readyz。
10. 一致性备份、恢复演练、版本化迁移。

不做：真实支付、银行接口、AI 必需依赖、多币种核算、广告/商城/社区/证券行情。
