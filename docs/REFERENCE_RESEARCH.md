## 关键许可结论

- **BeeCount** 使用自定义许可（版本 1.0，2025-01-29 生效）：个人/非营利免费，商业使用需付费授权。结论：**不复制其任何代码、文案、图标**；仅研究其中文家庭分类与导入行为作为业务参考。
- **Firefly III / Paisa（AGPL-3.0）、Cashew / Wallos（GPL-3.0）、MMEX（GPL-2.0）**：网络/分发场景有强著佐权义务。小账发布许可未定，结论：**不复制其源码与测试**；仅研究业务行为与边界用例。
- **Actual（MIT）**：许可宽松，但按既定策略仍独立实现，仅借鉴同步与离线体验设计。
