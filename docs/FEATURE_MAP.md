## 实施备注

- discount 拆分账务：借 费用:分类（应付全额）；贷 费用:分类（优惠额）；贷 资产（实付）。净费用 = 实付。
- 资金操作类型（本阶段）：lend 借出 / borrow 借入 / repay 还本金 / loan_repay 房贷车贷还款（本金+利息）/ redeem 理财赎回（本金+已确认收益）。押金经 lend+settle 语义。
- 所有新增保持：整数分、复式平衡、幂等、有效投影一致。
